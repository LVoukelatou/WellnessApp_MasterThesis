# Wellness App

Μια mobile εφαρμογή ευεξίας που συνδυάζει ερωτηματολόγια αυτοαξιολόγησης (Check-ins) με την ανάγνωση βιοσημάτων (μέσω Health Connect) για τον υπολογισμό και την παρακολούθηση του καθημερινού στρες υπαλλήλων γραφείου.

## Δομή του Project
Το αποθετήριο χωρίζεται σε δύο βασικά μέρη:
* `flutter_app`: Ο κώδικας της mobile εφαρμογής (Front-end).
* `flask_backend`: Το API σε Python που αναλαμβάνει τον υπολογισμό του αλγορίθμου στρες (Back-end).

## Οδηγίες Εκτέλεσης

### 1. Εκκίνηση του Backend (Python)
1. Άνοιγμα τερματικού στον φάκελο `flask_backend`.
2. Εγκατάστασγ του Flask αν δεν υπάρχει: `pip install flask`
3. Τρέξιμο του server: `python app.py`

### 2. Εκκίνηση του Frontend (Flutter)
**Σημαντική Σημείωση:** Πριν τρέξετε την εφαρμογή, μεταβείτε στο αρχείο `api_services.dart` μέσα στο Flutter project και αλλάξτε τη διεύθυνση IP (π.χ. `192.168.X.X`) ώστε να αντιστοιχεί στην τοπική IP του υπολογιστή σας που τρέχει το Flask.
